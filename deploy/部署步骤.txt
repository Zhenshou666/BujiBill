不记账本 · 服务器部署（Ubuntu 22.04 / 24.04）

一、装 Docker
  curl -fsSL https://get.docker.com | sh
  systemctl enable --now docker

二、放代码
  把 不记账本Demo_部署包.zip 传上去（宝塔面板上传，或本地执行：
  scp 不记账本Demo_部署包.zip root@你的服务器IP:/opt/）
  cd /opt && unzip 不记账本Demo_部署包.zip -d billbook && cd billbook

三、起服务
  docker compose up -d --build

四、打开
  http://你的服务器IP:8501

常用命令
  看日志：docker logs -f billbook
  重启：  docker compose restart
  停掉：  docker compose down
  改回私人账本：编辑 docker-compose.yml 把 BILLKIT_SHARE 改成 "0"，再 docker compose up -d

注意
  · 云服务器「防火墙/安全组」要放行 8501 端口，否则外面打不开
  · 用 IP:8501 访问不需要备案；要用域名 + 80/443 才需要 ICP 备案
